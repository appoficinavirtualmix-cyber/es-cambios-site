Política de Privacidad

Versión para la aplicación Android ES Cambios, package com.eschangue.escambios. Última actualización: 10 de agosto de 2026.

Datos pendientes para completar:

MUUVIX TECNOLOGIA E SOLUCOES LOGISTICAS LTDA, CNPJ 68.386.391/0001-68, AV. ALBATROZ 548, FAZENDA RIO GRANDE, PR, CEP: 83.823-448 y muuvix.suporte@gmail.com.

1. Responsable

ES Cambios es una aplicación para operaciones de cambio y remesas. El responsable del tratamiento será identificado como MUUVIX TECNOLOGIA E SOLUCOES LOGISTICAS LTDA, con canal de contacto de privacidad muuvix.suporte@gmail.com.

2. Información que recogemos

Podemos recoger y tratar información necesaria para registro, seguridad, cumplimiento y ejecución de operaciones financieras, incluyendo:

  • Nombre, apellido, correo electrónico, teléfono y país.
  • CPF u otros datos/documentos de identificación cuando corresponda.
  • Dirección y datos complementarios necesarios para verificación o cumplimiento.
  • Documentos de identidad, fotografías de documentos, selfie, datos capturados por cámara y resultados de OCR.
  • Beneficiarios o destinatarios, métodos de recepción y datos necesarios para procesar remesas.
  • Órdenes, importes, monedas, tasas, estados e historial de operaciones.
  • Tokens de notificación, identificadores técnicos del dispositivo, registros técnicos de seguridad y almacenamiento local necesario.
  • Uso de biometría y Android Keystore para proteger el acceso local cuando el usuario activa esa función.

3. Finalidades

Utilizamos la información para crear y administrar cuentas, verificar identidad, procesar órdenes, mostrar estados, prevenir fraude, cumplir obligaciones legales o regulatorias, brindar soporte, enviar notificaciones operativas y proteger la seguridad de la aplicación.

4. KYC y verificación de identidad

ES Cambios puede solicitar KYC, documentos de identidad, fotografías, selfie, cámara y OCR para validar datos, apoyar revisión humana, reducir fraude y cumplir requisitos aplicables. La verificación puede incluir análisis automatizado y revisión manual, sin que una medición técnica sustituya por sí sola una decisión final cuando sea necesaria una evaluación humana.

5. Proveedores e infraestructura

La aplicación utiliza Supabase como infraestructura/backend para autenticación operativa de la app, base de datos, funciones y almacenamiento de información necesaria. También utiliza Firebase Cloud Messaging para notificaciones push, incluyendo tokens de notificación y datos mínimos necesarios para entregar avisos.

No afirmamos el uso de Firebase Authentication. Firebase se declara aquí únicamente para notificaciones push mediante Firebase Cloud Messaging.

6. Notificaciones

ES Cambios puede enviar notificaciones sobre estados de remesas, pagos, seguridad de cuenta y eventos operativos importantes. El usuario puede administrar permisos de notificación desde el sistema operativo Android.

7. Seguridad

Aplicamos medidas técnicas y organizativas razonables para proteger la información. La app puede usar almacenamiento local, biometría y Android Keystore para proteger el acceso en el dispositivo. Ningún sistema es completamente infalible, por lo que recomendamos mantener el dispositivo actualizado y no compartir credenciales.

8. Conservación

Conservamos datos mientras sean necesarios para prestar el servicio, cumplir obligaciones legales, regulatorias, contables, antifraude o de cumplimiento, resolver disputas y mantener registros de operaciones financieras. Algunos datos pueden conservarse aunque el usuario solicite eliminación, cuando exista una obligación válida de conservación.

9. Transferencias internacionales

Por la naturaleza de la infraestructura tecnológica y de las operaciones de cambio/remesas, la información puede ser tratada o almacenada en países distintos al del usuario. Cuando corresponda, se aplicarán medidas adecuadas de protección y cumplimiento.

10. Derechos del usuario

El usuario puede solicitar acceso, corrección, actualización, eliminación, información sobre tratamiento y otros derechos aplicables según la ley correspondiente. Las solicitudes deben enviarse a muuvix.suporte@gmail.com y pueden requerir verificación de identidad.

11. Eliminación de cuenta

El usuario puede solicitar eliminación de cuenta desde la página Eliminar cuenta. La eliminación no implica borrar inmediatamente todos los registros si deben conservarse por motivos legales, regulatorios, contables, antifraude o de cumplimiento.
