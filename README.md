# ES Cambios - sitio oficial

Sitio estatico para GitHub Pages y dominio personalizado `es-cambios.com.br`.

- `/`
- `/privacidad/`
- `/privacidade/`
- `/excluir-conta/`
- `/soporte/`

## Publicacion en GitHub Pages

1. Crear un repositorio para el sitio, por ejemplo `es-cambios-site`.
2. Subir el contenido de esta carpeta a la rama principal del repositorio.
3. En GitHub, abrir `Settings > Pages`.
4. En `Build and deployment`, seleccionar `Deploy from a branch`.
5. Seleccionar rama `main` y carpeta `/root`.
6. Confirmar que el archivo `CNAME` contiene exactamente `es-cambios.com.br`.
7. Configurar el DNS del dominio segun indique GitHub Pages.
