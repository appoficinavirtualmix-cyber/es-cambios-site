## Publicación futura en GitHub Pages

1. Subir los cambios aprobados a la rama `main`.
2. Abrir `Settings > Pages` en GitHub.
3. Elegir `Deploy from a branch`, rama `main` y carpeta `/root`.
4. Confirmar que `CNAME` contiene exactamente `es-cambios.com.br`.
5. Configurar el DNS con los valores que GitHub indique para el dominio personalizado.
6. Activar HTTPS cuando GitHub valide el dominio.

No se debe publicar ni modificar DNS durante el desarrollo sin autorización expresa.
